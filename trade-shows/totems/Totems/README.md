# Totems Julià Camper — carpeta completa (v2)

Estructura idèntica a l'original. Per veure les 3 pantalles del Yosemite obre
directament (doble clic) qualsevol de:

    Yosemite4x4/highlights.htm
    Yosemite4x4/basic.htm
    Yosemite4x4/expo.htm

## Què és de mostra (substitueix-ho pels teus fitxers reals)
- `assets/` : bootstrap i llibreries són versions mínimes de mostra només
  perquè els HTML es vegin. Posa-hi els teus assets reals a sobre.
- `Imatges/Julia_Camper_logo.png`, `Imatges/yosemitte_plan.png` : placeholders.
- `Imatges/videos furgo junts.mp4` : NO inclòs (posa-hi el teu vídeo real;
  highlights.htm ja el reprodueix amb un <video> estàndard).

## Què és nou (el disseny v2)
- `estils.css` : nou look & feel (tipografia Plus Jakarta Sans, colors, targetes).
- `totem-v2.js` : portada highlights (destacats) + ajust automàtic perquè
  preu + configuració càpiguen en una sola pantalla 1080x1920 sense scroll.
- `Imatges/Julia_logo_white.png` / `Julia_logo_black.png` : logo Julià real.
- Els 3 HTML del Yosemite actualitzats al disseny nou.

Els altres models (GranAzur, GranYosemite, SportClub, Yellowstone) i les
versions `_ger` es mantenen com estaven.
