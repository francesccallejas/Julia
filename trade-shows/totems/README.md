# Totems Julià Camper

Tres carpetes, cadascuna SENCERA i autònoma (mateixa estructura del projecte).
L'única cosa que canvia entre elles són els 3 HTML del Yosemite i el CSS:

- **original/** : tal com estava (estils.css original, HTML originals).
- **v1/**       : mateix HTML original, només amb el `estils.css` nou (restyle).
- **v2/**       : disseny final — 3 HTML nous (highlights/basic/expo) + `estils.css`
                  + `totem-v2.js` (portada marketing + ajust automàtic a pantalla).

Per veure-ho: obre (doble clic) `<versio>/Yosemite4x4/highlights.htm` (o basic/expo).

## Nota sobre assets (IMPORTANT)
El ZIP original va arribar amb `assets/` i `Imatges/` BUIDES, així que aquí hi ha
versions de MOSTRA (bootstrap mínim, imatges placeholder, logo Julià real) només
perquè els HTML es vegin. Substitueix `assets/` i `Imatges/` pels teus reals
(bootstrap complet, imatges, i el vídeo `Imatges/videos furgo junts.mp4`).
